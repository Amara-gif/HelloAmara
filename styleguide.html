Breakpoints and layout sizes

Breakpoints are tokens, but @media cannot read custom properties, so components.css repeats these literal widths and must stay in sync.

Buttons

One button base with secondary (the default), primary, ghost, danger, link and icon variants. Use the class order btn btn-<variant> btn-<size> (variant before size); the bare default below documents the base class. Use -sm, the default or -md to make the size explicit; touch targets stay at least 44 px.

Button states

Every variant shares the same state model. Hover and active are guarded by :not(:disabled), so a disabled button never changes. Focus-visible gets the shared token outline, aria-pressed adds the pressed ring, and aria-busy shows the CSS-only spinner. Preview classes is-hover, is-active and is-focus-visible make static samples visible without interaction.

Selectable pills

Tabs, chips and nav links share one selected look: the --color-nav-active fill, --color-text and --font-weight-semibold. Hover uses the surface tokens and stays separate, so a hovered unselected chip never looks selected. The is-hover and is-focus-visible preview classes show the states without interaction; aria-selected, aria-current and aria-pressed are the real selected hooks, with is-active kept as an alias.
