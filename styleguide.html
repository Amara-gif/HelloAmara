Style guide

Every token and shared component lives on this page. Values are read from tokens.css for the current colour scheme. Add a component here in the same commit that introduces it.

Colour tokens

Defined once in assets/css/tokens.css. Pages never use colour literals.

Typography tokens

System fonts only. No web fonts and no third-party font requests.

Spacing tokens

One 4 px-based scale for padding, margins and gaps.

Radius tokens

Shadow tokens

Breakpoints and layout sizes

Breakpoints are tokens, but @media cannot read custom properties, so components.css repeats these literal widths and must stay in sync.

Sidebar fold and pin

Desktop-only controls. Fold collapses the sidebar and is remembered in localStorage; pin keeps it open, and a folded sidebar shows the floating reopen button. Below 900 px the sidebar remains the existing drawer.

Chart container

Charts are drawn only by assets/js/chart.js. No chart library and no CDN.
